# TPDrawerMenu

Projet d'apprentissage mobile créé avec **React Native** et **Expo**.

## État du dépôt

À ce stade, le code contient la structure initiale d'une application Expo : une vue d'accueil simple avec un texte et la barre d'état. Le menu latéral (Drawer) annoncé dans le nom du dépôt **n'est pas encore implémenté**.

## Environnement technique

- React Native 0.81
- React 19
- Expo SDK 54
- JavaScript

## Lancement local

```bash
npm install
npm start
```

Utiliser ensuite Expo Go ou une des options proposées par Expo pour ouvrir l'application sur l'environnement souhaité.

## Évolutions envisageables

- Ajouter une navigation latérale avec React Navigation.
- Créer plusieurs écrans et gérer les déplacements entre vues.
- Améliorer l'interface et vérifier son comportement sur Android et iOS.

Ce dépôt correspond à un **exercice en cours**, et non à une application mobile finalisée.
